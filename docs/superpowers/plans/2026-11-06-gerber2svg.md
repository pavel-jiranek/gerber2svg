# gerber2svg Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `gerber2svg` package and CLI that turns one copper Gerber file and an optional outline into a physically dimensioned SVG of copper, negative copper, or an isolation band.

**Architecture:** Gerbonara 1.6.3 renders apertures into graphic primitives. This project polygonizes those primitives, composites dark and clear polarity in file order, builds a board polygon, runs one of the three modes with Shapely, and writes SVG with the standard-library XML library. The CLI calls `convert()` and does not own geometry.

**Tech Stack:** Python 3.11+, Gerbonara 1.6.3, Shapely 2, Typer, pytest, `xml.etree.ElementTree`.

## Global Constraints

- Python 3.11 or newer. Type annotations throughout.
- Pin `gerbonara==1.6.3`. Runtime dependencies are Gerbonara, Shapely, and Typer. Tests use pytest. Do not depend on `svgwrite`.
- Internal geometry is millimeters, Y upward, until SVG export.
- `operations.py` does not import the SVG writer. `svg.py` does not import the Gerber parser. `cli.py` only parses arguments, calls `convert`, prints diagnostics, and writes the output file.
- Composite polarity in file order. A single union of every dark primitive is not the copper image.
- Read `polarity_dark` from the source primitive, including when `to_arc_poly()` is used to get the outline.
- Curve tolerance default is `0.005` mm and must be greater than zero. Full circles use at least 4 segments. Sagitta must be at most the curve tolerance.
- Clearance default is `0`. A nonzero clearance is valid only in negative mode and must be positive. Width is required for isolation, must be greater than zero, and is an error in any other mode.
- Margin default is `0` and must be zero or positive. A nonzero margin together with an outline file is a `ConfigError`.
- Default origin is `board-min`. Default SVG strategy is `compound`.
- Repair invalid geometry with `make_valid`. Warn with the area before and after. Raise `GeometryError` if the absolute area change is greater than `0.001` mm².
- Outline endpoints join within `0.01` mm. A larger gap raises `OutlineError` and includes the gap distance.
- A file containing `IPNEG` raises `UnsupportedGerberError`. Gerbonara flips object flags for negative image polarity and does not paint the dark background, so the file is refused.
- Empty copper with no outline raises `OutlineError`. Empty copper with a valid outline warns and continues.
- Copper mode exports `C` unclipped. Negative and isolation results are clipped to `B` by construction.
- Export bounds are the axis-aligned bounds of the union of the mode geometry and `B`.
- `board-min` maps Gerber `(x, y)` to SVG `(x - minx, maxy - y)` and uses view box `0 0 W H`.
- `preserve` maps Gerber `(x, y)` to SVG `(x, -y)` and uses view box `{minx} {-maxy} {W} {H}`. `width` and `height` are always `{W}mm` and `{H}mm`.
- Path data is absolute `M`, `L`, and `Z` only, 6 decimal places, no scientific notation. Fill is black. `fill-rule="evenodd"`. No stroke, style sheet, text, image, mask, or clip path.
- Exact Shapely comparisons allow at most `1e-6` mm² of symmetric-difference area. Arc fixtures whose ideal area is known allow at most `curve_tolerance_mm` times the ideal perimeter.
- Isolation coverage warns when the outward skin outside the band has area greater than `0.0001` mm².
- Exit codes: `0` success including warnings, `2` configuration, `3` Gerber or outline, `4` geometry, `5` SVG write. Typer usage errors also exit `2`.
- Drills, batch conversion, ZIP input, multi-layer boards, preview images, and the other phase 6 items stay out.
- This version does not claim LightBurn or MillMage have imported the files.

from dataclasses import dataclass
from enum import Enum
from pathlib import Path

from shapely.geometry.base import BaseGeometry

from gerber2svg.exceptions import ConfigError


class Mode(str, Enum):
    COPPER = "copper"
    NEGATIVE = "negative"
    ISOLATION = "isolation"


class Origin(str, Enum):
    PRESERVE = "preserve"
    BOARD_MIN = "board-min"


class SvgStrategy(str, Enum):
    COMPOUND = "compound"
    CONTOURS = "contours"


@dataclass
class ConversionConfig:
    copper: Path
    outline: Path | None = None
    mode: Mode = Mode.NEGATIVE
    clearance_mm: float = 0.0
    width_mm: float | None = None
    curve_tolerance_mm: float = 0.005
    svg_strategy: SvgStrategy = SvgStrategy.COMPOUND
    margin_mm: float = 0.0
    origin: Origin = Origin.BOARD_MIN
    mirror_x: bool = False
    mirror_y: bool = False


@dataclass
class ConversionResult:
    copper: BaseGeometry
    board: BaseGeometry
    geometry: BaseGeometry
    svg: str
    warnings: list[str]
    primitive_count: int


def validate_config(config: ConversionConfig) -> None:
    if config.curve_tolerance_mm <= 0:
        raise ConfigError("curve tolerance must be greater than zero")
    if config.margin_mm < 0:
        raise ConfigError("margin must be zero or positive")
    if config.clearance_mm < 0:
        raise ConfigError("clearance must be zero or positive")
    if config.clearance_mm != 0 and config.mode is not Mode.NEGATIVE:
        raise ConfigError("clearance is only valid in negative mode")
    if config.mode is Mode.ISOLATION:
        if config.width_mm is None:
            raise ConfigError("isolation mode requires --width")
        if config.width_mm <= 0:
            raise ConfigError("isolation width must be greater than zero")
    elif config.width_mm is not None:
        raise ConfigError("width is only valid in isolation mode")
    if config.outline is not None and config.margin_mm != 0:
        raise ConfigError("margin cannot be combined with an outline file")

```python
from shapely import make_valid, union_all
from shapely.geometry import MultiPolygon, Polygon
from shapely.geometry.base import BaseGeometry

from gerber2svg.exceptions import GeometryError

REPAIR_AREA_LIMIT_MM2 = 0.001


def as_polygonal(geom: BaseGeometry) -> BaseGeometry:
    if geom.is_empty:
        return Polygon()
    if isinstance(geom, (Polygon, MultiPolygon)):
        return geom
    polygons = [part for part in getattr(geom, "geoms", []) if isinstance(part, Polygon) and not part.is_empty]
    if not polygons:
        return Polygon()
    if len(polygons) == 1:
        return polygons[0]
    return MultiPolygon(polygons)


def repair(geom: BaseGeometry) -> tuple[BaseGeometry, list[str]]:
    if geom.is_empty:
        return Polygon(), []
    if geom.is_valid and isinstance(geom, (Polygon, MultiPolygon)):
        return geom, []
    before = float(geom.area)
    fixed = as_polygonal(make_valid(geom))
    after = float(fixed.area)
    warnings = [f"repaired invalid geometry: area {before:.6f} -> {after:.6f} mm^2"]
    if abs(after - before) > REPAIR_AREA_LIMIT_MM2:
        raise GeometryError(
            f"geometry repair changed area by {abs(after - before):.6f} mm^2 "
            f"({before:.6f} -> {after:.6f})"
        )
    return fixed, warnings


def union_geometries(geoms: list[BaseGeometry]) -> tuple[BaseGeometry, list[str]]:
    present = [geom for geom in geoms if not geom.is_empty]
    if not present:
        return Polygon(), []
    if len(present) == 1:
        return repair(present[0])
    return repair(union_all(present))


def difference_geometries(left: BaseGeometry, right: BaseGeometry) -> tuple[BaseGeometry, list[str]]:
    if left.is_empty or right.is_empty:
        return repair(left)
    return repair(left.difference(right))


def intersection_geometries(left: BaseGeometry, right: BaseGeometry) -> tuple[BaseGeometry, list[str]]:
    if left.is_empty or right.is_empty:
        return Polygon(), []
    return repair(left.intersection(right))
```

```python
import math

from shapely.affinity import scale


def buffer_resolution(radius_mm: float, curve_tolerance_mm: float) -> int:
    if radius_mm <= 0 or curve_tolerance_mm >= radius_mm:
        return 8
    theta = 2 * math.acos(1 - (curve_tolerance_mm / radius_mm))
    quarter = math.pi / 2
    return max(8, math.ceil(quarter / theta))


def buffer_mm(
    geom: BaseGeometry, distance_mm: float, curve_tolerance_mm: float
) -> tuple[BaseGeometry, list[str]]:
    if distance_mm == 0 or geom.is_empty:
        return geom, []
    resolution = buffer_resolution(abs(distance_mm), curve_tolerance_mm)
    buffered = geom.buffer(
        distance_mm,
        quad_segs=resolution,
        cap_style="round",
        join_style="round",
    )
    return repair(buffered)


def mirror_geometry(geom: BaseGeometry, mirror_x: bool, mirror_y: bool) -> BaseGeometry:
    if geom.is_empty or (not mirror_x and not mirror_y):
        return geom
    return scale(
        geom,
        xfact=-1.0 if mirror_x else 1.0,
        yfact=-1.0 if mirror_y else 1.0,
        origin=(0.0, 0.0),
    )
```

```python
import xml.etree.ElementTree as ET

from shapely.geometry import MultiPolygon, Polygon
from shapely.geometry.base import BaseGeometry
from shapely.ops import unary_union

from gerber2svg.models import Origin, SvgStrategy

SVG_NS = "http://www.w3.org/2000/svg"
ET.register_namespace("", SVG_NS)


def export_bounds(geometry: BaseGeometry, board: BaseGeometry) -> tuple[float, float, float, float]:
    parts = [geom for geom in (geometry, board) if geom is not None and not geom.is_empty]
    if not parts:
        return (0.0, 0.0, 0.0, 0.0)
    merged = parts[0] if len(parts) == 1 else unary_union(parts)
    minx, miny, maxx, maxy = merged.bounds
    return (float(minx), float(miny), float(maxx), float(maxy))


def _polygons(geom: BaseGeometry) -> list[Polygon]:
    if geom.is_empty:
        return []
    if isinstance(geom, Polygon):
        return [geom]
    if isinstance(geom, MultiPolygon):
        return [part for part in geom.geoms if isinstance(part, Polygon) and not part.is_empty]
    return []


def _format_pair(x: float, y: float) -> str:
    return f"{x:.6f} {y:.6f}"


def _ring_path(ring, transform) -> str:
    coords = list(ring.coords)
    if len(coords) >= 2 and coords[0] == coords[-1]:
        coords = coords[:-1]
    if len(coords) < 3:
        return ""
    parts = [f"M {_format_pair(*transform(*coords[0]))}"]
    for x, y in coords[1:]:
        parts.append(f"L {_format_pair(*transform(x, y))}")
    parts.append("Z")
    return " ".join(parts)


def _transform_for(origin: Origin, minx: float, maxy: float):
    if origin is Origin.BOARD_MIN:
        return lambda x, y: (x - minx, maxy - y)
    return lambda x, y: (x, -y)


def _view_box(origin: Origin, minx: float, miny: float, maxx: float, maxy: float) -> str:
    width = maxx - minx
    height = maxy - miny
    if origin is Origin.BOARD_MIN:
        vx, vy = 0.0, 0.0
    else:
        vx, vy = minx, -maxy
    return f"{vx:.6f} {vy:.6f} {width:.6f} {height:.6f}"


def geometry_to_svg(
    geometry: BaseGeometry,
    board: BaseGeometry,
    *,
    origin: Origin,
    strategy: SvgStrategy,
) -> tuple[str, list[str]]:
    warnings: list[str] = []
    minx, miny, maxx, maxy = export_bounds(geometry, board)
    width = maxx - minx
    height = maxy - miny
    if width == 0 and height == 0:
        warnings.append("exported geometry and board are empty")
    transform = _transform_for(origin, minx, maxy)
    polygons = _polygons(geometry)
    paths: list[str] = []
    if strategy is SvgStrategy.CONTOURS:
        for polygon in polygons:
            for ring in (polygon.exterior, *polygon.interiors):
                data = _ring_path(ring, transform)
                if data:
                    paths.append(data)
    else:
        subpaths = []
        for polygon in polygons:
            for ring in (polygon.exterior, *polygon.interiors):
                data = _ring_path(ring, transform)
                if data:
                    subpaths.append(data)
        if subpaths:
            paths.append(" ".join(subpaths))

    root = ET.Element(
        f"{{{SVG_NS}}}svg",
        {
            "width": f"{width:.6f}mm",
            "height": f"{height:.6f}mm",
            "viewBox": _view_box(origin, minx, miny, maxx, maxy),
        },
    )
    for data in paths:
        ET.SubElement(
            root,
            f"{{{SVG_NS}}}path",
            {"fill": "black", "fill-rule": "evenodd", "d": data},
        )
    xml = ET.tostring(root, encoding="unicode", xml_declaration=False)
    return xml, warnings

```python
from shapely.geometry.base import BaseGeometry

from gerber2svg.geometry import buffer_mm, difference_geometries, intersection_geometries
from gerber2svg.models import ConversionConfig, Mode

COVERAGE_AREA_MM2 = 0.0001


def isolation_coverage_warnings(
    copper: BaseGeometry,
    board: BaseGeometry,
    isolation: BaseGeometry,
    *,
    curve_tolerance_mm: float,
    width_mm: float,
) -> list[str]:
    if copper.is_empty or width_mm <= 0:
        return []
    skin_distance = min(curve_tolerance_mm, width_mm / 2)
    skin, _warnings = buffer_mm(copper, skin_distance, curve_tolerance_mm)
    skin, _warnings = difference_geometries(skin, copper)
    skin, _warnings = intersection_geometries(skin, board)
    outside, _warnings = difference_geometries(skin, isolation)
    if outside.area > COVERAGE_AREA_MM2:
        return ["isolation band does not fully surround copper inside the board"]
    return []


def run_mode(
    copper: BaseGeometry, board: BaseGeometry, config: ConversionConfig
) -> tuple[BaseGeometry, list[str]]:
    warnings: list[str] = []
    if config.mode is Mode.COPPER:
        return copper, warnings
    if config.mode is Mode.NEGATIVE:
        protected = copper
        if config.clearance_mm > 0:
            protected, buffer_warnings = buffer_mm(
                copper, config.clearance_mm, config.curve_tolerance_mm
            )
            warnings.extend(buffer_warnings)
        result, difference_warnings = difference_geometries(board, protected)
        warnings.extend(difference_warnings)
        return result, warnings

    assert config.width_mm is not None
    expanded, buffer_warnings = buffer_mm(copper, config.width_mm, config.curve_tolerance_mm)
    warnings.extend(buffer_warnings)
    band, difference_warnings = difference_geometries(expanded, copper)
    warnings.extend(difference_warnings)
    result, clip_warnings = intersection_geometries(band, board)
    warnings.extend(clip_warnings)
    warnings.extend(
        isolation_coverage_warnings(
            copper,
            board,
            result,
            curve_tolerance_mm=config.curve_tolerance_mm,
            width_mm=config.width_mm,
        )
    )
    return result, warnings
```

```python
from dataclasses import dataclass

from shapely.geometry import Polygon
from shapely.geometry.base import BaseGeometry

from gerber2svg.exceptions import UnsupportedGerberError
from gerber2svg.geometry import difference_geometries, repair, union_geometries


@dataclass
class Painted:
    polygon: BaseGeometry
    polarity_dark: bool


def primitive_to_polygon(primitive, curve_tolerance_mm: float) -> BaseGeometry | None:
    from gerbonara.graphic_primitives import Arc, ArcPoly, Circle, Line, Rectangle

    if not isinstance(primitive, (Circle, Rectangle, Line, Arc, ArcPoly)):
        raise UnsupportedGerberError(
            f"unsupported primitive {type(primitive).__name__}"
        )
    flat = primitive.to_arc_poly().approximate_arcs(
        max_error=curve_tolerance_mm, clip_max_error=True
    )
    if len(flat.outline) < 3:
        return None
    polygon, _warnings = repair(Polygon(flat.outline))
    if polygon.is_empty or polygon.area == 0:
        return None
    return polygon


def composite_painted(painted: list[Painted]) -> tuple[BaseGeometry, list[str]]:
    warnings: list[str] = []
    image: BaseGeometry = Polygon()
    group: list[BaseGeometry] = []
    group_dark: bool | None = None

    def flush() -> None:
        nonlocal image, group, group_dark
        if not group or group_dark is None:
            group = []
            group_dark = None
            return
        merged, union_warnings = union_geometries(group)
        warnings.extend(union_warnings)
        if group_dark:
            if image.is_empty:
                image = merged
            else:
                image, more = union_geometries([image, merged])
                warnings.extend(more)
        elif image.is_empty:
            warnings.append("clear polarity applied to empty copper")
        else:
            image, more = difference_geometries(image, merged)
            warnings.extend(more)
        group = []
        group_dark = None

    for item in painted:
        if group_dark is None:
            group_dark = item.polarity_dark
        elif item.polarity_dark != group_dark:
            flush()
            group_dark = item.polarity_dark
        group.append(item.polygon)
    flush()
    return image, warnings
```

from pathlib import Path

from gerbonara import GerberFile
from gerbonara.utils import MM

from gerber2svg.exceptions import GerberError, UnsupportedGerberError


def _primitive_position(primitive) -> str:
    if hasattr(primitive, "x") and hasattr(primitive, "y"):
        return f"{float(primitive.x):.4f},{float(primitive.y):.4f}"
    if hasattr(primitive, "x1") and hasattr(primitive, "y1"):
        return f"{float(primitive.x1):.4f},{float(primitive.y1):.4f}"
    return "unknown"


def load_copper(path: Path, curve_tolerance_mm: float) -> tuple[BaseGeometry, list[str], int]:
    if not path.is_file():
        raise GerberError(f"copper file not found: {path}")
    text = path.read_text(encoding="utf-8")
    if "IPNEG" in text:
        raise UnsupportedGerberError("negative image polarity (%IPNEG*%) is not supported")
    try:
        gerber = GerberFile.from_string(text, filename=str(path))
    except Exception as exc:
        raise GerberError(f"invalid Gerber file {path}: {exc}") from exc

    painted: list[Painted] = []
    warnings: list[str] = []
    primitive_count = 0
    for index, obj in enumerate(gerber.objects):
        try:
            primitives = list(obj.to_primitives(MM))
        except Exception as exc:
            raise GerberError(f"cannot render object {index} in {path}: {exc}") from exc
        for primitive in primitives:
            primitive_count += 1
            polygon = primitive_to_polygon(primitive, curve_tolerance_mm)
            if polygon is None:
                warnings.append(
                    f"omitted zero-area {type(primitive).__name__} at {_primitive_position(primitive)}"
                )
                continue
            painted.append(Painted(polygon, bool(primitive.polarity_dark)))
    copper, composite_warnings = composite_painted(painted)
    warnings.extend(composite_warnings)
    return copper, warnings, primitive_count

```python
import math

from shapely.geometry import MultiPolygon, Polygon

from gerber2svg.exceptions import OutlineError
from gerber2svg.geometry import repair

SNAP_MM = 0.01


def _close_enough(start: tuple[float, float], end: tuple[float, float]) -> bool:
    return math.hypot(start[0] - end[0], start[1] - end[1]) <= SNAP_MM


def _outline_polylines(path: Path, curve_tolerance_mm: float) -> list[list[tuple[float, float]]]:
    from gerbonara.graphic_objects import Arc, Flash, Line, Region
    from gerbonara.utils import approximate_arc

    if not path.is_file():
        raise OutlineError(f"outline file not found: {path}")
    try:
        gerber = GerberFile.open(path)
    except Exception as exc:
        raise OutlineError(f"invalid outline file {path}: {exc}") from exc

    polylines: list[list[tuple[float, float]]] = []
    for obj in gerber.objects:
        if isinstance(obj, Line):
            converted = obj.converted(MM)
            polylines.append(
                [(float(converted.x1), float(converted.y1)), (float(converted.x2), float(converted.y2))]
            )
        elif isinstance(obj, Arc):
            converted = obj.converted(MM)
            points = [
                (float(x), float(y))
                for x, y in approximate_arc(
                    float(converted.cx),
                    float(converted.cy),
                    float(converted.x1),
                    float(converted.y1),
                    float(converted.x2),
                    float(converted.y2),
                    converted.clockwise,
                    max_error=curve_tolerance_mm,
                )
            ]
            if len(points) >= 2:
                polylines.append(points)
        elif isinstance(obj, Region):
            primitive = next(obj.to_primitives(MM))
            flat = primitive.approximate_arcs(max_error=curve_tolerance_mm)
            polylines.append([(float(x), float(y)) for x, y in flat.outline])
        elif isinstance(obj, Flash):
            raise OutlineError("outline contains a flash, which has no centerline")
        else:
            raise OutlineError(f"unsupported outline object {type(obj).__name__}")
    return polylines


def _chain_rings(polylines: list[list[tuple[float, float]]]) -> list[list[tuple[float, float]]]:
    unused = [list(line) for line in polylines if len(line) >= 2]
    rings: list[list[tuple[float, float]]] = []
    while unused:
        chain = unused.pop(0)
        progressed = True
        while progressed and not _close_enough(chain[0], chain[-1]):
            progressed = False
            for index, other in enumerate(unused):
                if _close_enough(chain[-1], other[0]):
                    chain.extend(other[1:])
                    unused.pop(index)
                    progressed = True
                    break
                if _close_enough(chain[-1], other[-1]):
                    chain.extend(list(reversed(other[:-1])))
                    unused.pop(index)
                    progressed = True
                    break
        if not _close_enough(chain[0], chain[-1]):
            gap = math.hypot(chain[0][0] - chain[-1][0], chain[0][1] - chain[-1][1])
            raise OutlineError(f"outline contour is open by {gap:.4f} mm")
        rings.append(chain)
    if not rings:
        raise OutlineError("outline contains no contours")
    return rings


def _rings_to_board(rings: list[list[tuple[float, float]]]) -> BaseGeometry:
    shapes = []
    for ring in rings:
        polygon, _warnings = repair(Polygon(ring))
        if isinstance(polygon, MultiPolygon):
            shapes.extend(part for part in polygon.geoms if part.area > 0)
        elif not polygon.is_empty and polygon.area > 0:
            shapes.append(polygon)
    if not shapes:
        raise OutlineError("outline produced empty geometry")

    def depth(shape: Polygon) -> int:
        point = shape.representative_point()
        return sum(
            1
            for other in shapes
            if other is not shape and other.area > shape.area and other.contains(point)
        )

    outers = [shape for shape in shapes if depth(shape) % 2 == 0]
    holes = [shape for shape in shapes if depth(shape) % 2 == 1]
    built: list[Polygon] = []
    for outer in outers:
        own_holes = [
            hole.exterior
            for hole in holes
            if depth(hole) == depth(outer) + 1 and outer.contains(hole.representative_point())
        ]
        built.append(Polygon(outer.exterior, own_holes))
    board: BaseGeometry = built[0] if len(built) == 1 else MultiPolygon(built)
    board, _warnings = repair(board)
    if board.is_empty or board.area <= 0:
        raise OutlineError("outline has no positive area")
    return board


def load_outline(path: Path, curve_tolerance_mm: float) -> tuple[BaseGeometry, list[str]]:
    rings = _chain_rings(_outline_polylines(path, curve_tolerance_mm))
    return _rings_to_board(rings), []
```

"""Convert Gerber copper artwork into SVG geometry."""

from shapely.geometry import box

from gerber2svg.exceptions import OutlineError
from gerber2svg.geometry import mirror_geometry
from gerber2svg.gerber import load_copper, load_outline
from gerber2svg.models import ConversionConfig, ConversionResult, validate_config
from gerber2svg.operations import run_mode
from gerber2svg.svg import geometry_to_svg

__version__ = "0.1.0"


def convert(config: ConversionConfig) -> ConversionResult:
    validate_config(config)
    copper, warnings, primitive_count = load_copper(config.copper, config.curve_tolerance_mm)
    if config.outline is not None:
        board, outline_warnings = load_outline(config.outline, config.curve_tolerance_mm)
        warnings.extend(outline_warnings)
    elif copper.is_empty:
        raise OutlineError("cannot build a board rectangle from empty copper")
    else:
        minx, miny, maxx, maxy = copper.bounds
        margin = config.margin_mm
        board = box(minx - margin, miny - margin, maxx + margin, maxy + margin)
    if copper.is_empty:
        warnings.append("copper geometry is empty")
    copper = mirror_geometry(copper, config.mirror_x, config.mirror_y)
    board = mirror_geometry(board, config.mirror_x, config.mirror_y)
    geometry, mode_warnings = run_mode(copper, board, config)
    warnings.extend(mode_warnings)
    svg, svg_warnings = geometry_to_svg(
        geometry,
        board,
        origin=config.origin,
        strategy=config.svg_strategy,
    )
    warnings.extend(svg_warnings)
    return ConversionResult(
        copper=copper,
        board=board,
        geometry=geometry,
        svg=svg,
        warnings=warnings,
        primitive_count=primitive_count,
    )

    curve_tolerance: float = typer.Option(0.005, "--curve-tolerance", help="Maximum chord error in mm"),

    margin: float = typer.Option(0.0, "--margin", help="Margin for an automatic board rectangle, in mm"),
    origin: Origin = typer.Option(Origin.BOARD_MIN, "--origin"),
    mirror_x: bool = typer.Option(False, "--mirror-x"),
    mirror_y: bool = typer.Option(False, "--mirror-y"),
    verbose: bool = typer.Option(False, "--verbose"),
    version_flag: bool = typer.Option(False, "--version", callback=_version, is_eager=True),
) -> None:
    del version_flag
    config = ConversionConfig(
        copper=copper,
        outline=outline,
        mode=mode,
        clearance_mm=clearance,
        width_mm=width,
        curve_tolerance_mm=curve_tolerance,
        svg_strategy=svg_strategy,
        margin_mm=margin,
        origin=origin,
        mirror_x=mirror_x,
        mirror_y=mirror_y,
    )
    try:

    except ConfigError as exc:

        raise typer.Exit(code=2) from exc
    except (GerberError, OutlineError) as exc:

```markdown
# gerber2svg

`gerber2svg` converts one PCB copper Gerber file into an SVG of the copper, the board surface outside the copper, or a narrow isolation band. It is a geometry converter. LightBurn and MillMage still generate laser scan lines, milling toolpaths, feeds, and cutter compensation.

The automatic tests check geometry. LightBurn and MillMage import has not been verified.

## Supported Gerber

The converter reads RS-274X through Gerbonara 1.6.3, in millimeters or inches. It polygonizes circular, rectangular, and round-ended apertures, arcs, regions, aperture macros Gerbonara can render, and step-and-repeat blocks. Dark and clear polarity are applied in file order.

A standard aperture hole stays a hole. A file that contains `%IPNEG*%` is rejected. Negative image polarity needs a dark background that Gerbonara does not create. An unsupported primitive type is an error that names the type. Arcs are flattened with Gerbonara `approximate_arcs`, and the maximum sagitta is `--curve-tolerance` (default 0.005 mm).

Outline files are read as centerlines. Endpoints within 0.01 mm are joined. A contained closed ring is a cutout. An open contour is an error that reports the gap.

## Installation

```bash
pip install -e ".[dev]"
```

Requires Python 3.11 or newer.

## CLI

```bash
gerber2svg --copper board-F_Cu.gbr --outline board-Edge_Cuts.gbr --mode negative --output removal.svg
```

| Flag | Meaning |
|---|---|
| `--copper` | Copper Gerber file. Required. |
| `--outline` | Board outline Gerber. Optional. |
| `--output` | SVG path. Required. |
| `--mode` | `copper`, `negative`, or `isolation`. Required. |
| `--clearance` | Millimeters added around copper before a negative subtraction. Default 0. Valid only in negative mode. |
| `--width` | Isolation band width in millimeters. Required for isolation mode and rejected otherwise. |
| `--curve-tolerance` | Maximum chord error in millimeters. Default 0.005. |
| `--svg-strategy` | `compound` (default) or `contours`. |
| `--margin` | Extra millimeters around the copper bounds when no outline is given. Default 0. Rejected when an outline is given. |
| `--origin` | `board-min` (default) or `preserve`. |
| `--mirror-x`, `--mirror-y` | Flip in Gerber millimeters about the origin, before SVG export. |
| `--verbose` | Print the primitive count and areas. |
| `--help`, `--version` | Usage and package version. |

Exit codes: 0 success, including warnings; 2 configuration; 3 Gerber or outline; 4 geometry; 5 SVG write.

## Examples

```bash
gerber2svg --copper tests/fixtures/board_e2e_copper.gbr --outline tests/fixtures/board_e2e_outline.gbr --mode copper --output examples/copper.svg
gerber2svg --copper tests/fixtures/board_e2e_copper.gbr --outline tests/fixtures/board_e2e_outline.gbr --mode negative --output examples/negative.svg
gerber2svg --copper tests/fixtures/board_e2e_copper.gbr --outline tests/fixtures/board_e2e_outline.gbr --mode isolation --width 0.3 --output examples/isolation.svg
```

## LightBurn

Import `examples/negative.svg`. Check that the document is 20 mm by 12 mm. Put the graphic on a Fill layer. Preview it. The copper pad, track, and pour, including the hole in the pour, are the regions the laser should leave painted. This workflow has not been run in LightBurn yet.

## MillMage

Import `examples/isolation.svg` for a narrow removal band, or `examples/negative.svg` for a full pocket of the non-copper area. Check the 20 mm by 12 mm size. Choose a Profile or Pocket operation and a tool in MillMage. The SVG is the region to remove, not the cutter centerline. This workflow has not been run in MillMage yet.

## Copper and removal geometry

`copper` exports the interpreted copper, including any copper that extends outside the board. `negative` exports the board minus the copper. That is the paint the laser removes, or the region a pocketing operation clears. `isolation` exports a band of `--width` millimeters outside the copper and inside the board. Copper the Gerber file already joins stays joined. There is no netlist.

## Clearance and isolation width

`--clearance` expands the copper that negative mode protects. The painted or milled area gets smaller. It is not an electrical clearance, and it can reduce the gap between tracks.

`--width` is the width of the geometric removal band. It is not the cutter diameter. MillMage applies cutter compensation.

## Precision and coordinates

Geometry is calculated in millimeters. `--curve-tolerance` is the only intentional curve approximation. Boolean repairs that change the area by more than 0.001 mm² are errors. Smaller repairs are warnings.

Gerber Y points up. SVG Y points down. The exporter applies that flip for both origin modes. `--mirror-y` is a separate flip about the Gerber origin and happens before the SVG flip.

`--origin board-min` moves the minimum corner of the export bounds to the SVG origin. `--origin preserve` keeps Gerber X and writes Gerber Y as negative SVG Y. `width` and `height` are the physical size of those bounds in both modes. When a board exists, the bounds include the board, so a negative or isolation file stays board-sized.

With no outline, the board is the copper bounding box expanded by `--margin`. That rectangle is an approximation, not the manufactured PCB edge.

## Limitations

- One copper file and one optional outline per run.
- No Excellon drills, ZIP jobs, or multi-layer boards.
- `%IPNEG*%` is rejected.
- Isolation does not discover nets, so it cannot separate copper that the Gerber already connects.
- A missing isolation skin larger than 0.0001 mm² produces a warning.
- LightBurn and MillMage behavior is not yet verified. `contours` writes one closed path per ring, exterior before holes, for importers that treat nesting as a cutout. `compound` is the strategy to use until an importer shows otherwise.

## Troubleshooting

- `clearance is only valid in negative mode` or `width is only valid in isolation mode`: drop the flag that does not apply to `--mode`.
- `isolation mode requires --width`: pass `--width` in millimeters.
- `outline contour is open by N mm`: the edge-cuts drawing does not close. The message reports the gap.
- `negative image polarity (%IPNEG*%) is not supported`: export the layer as positive polarity from the CAD tool.
- `cannot build a board rectangle from empty copper`: pass `--outline`, or use a Gerber file that contains copper.
- A warning `clear polarity applied to empty copper` means a clear draw happened before any dark copper. Later dark draws are kept.
- A warning `repaired invalid geometry` includes the area before and after. An area change above 0.001 mm² stops the conversion.
